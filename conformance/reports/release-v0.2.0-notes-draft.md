# ContextIR v0.2.0

独立 Go package，实现固定 OpenH3-IR 提交 `fd031e136ae3d89147324c0d1b2aa65e838c21f5` 的公开 IR 编译流程。运行时仅使用 Go 标准库，不依赖 Python、CLW、数据库或队列。

- 支持五种模式、16 种素材职责、Compile/Refine、IR 保存读取、来源绑定、固定对白、身份组合、许可与有限修复。
- 本轮修复参考图排版混入身份、合并后遗漏未合并主体、音频属性错绑对象、跨镜文字约束和毫秒时长边界；真实失败候选及调用用量完整保留。
- Go 1.25.0 全库测试与 vet 通过；全库 race 通过：442 个主测试、7957 个子测试，0 失败、0 跳过。
- 同一冻结实现执行 35 Compile + 5 Refine：36 次产出、4 次按预期拒绝，277 次 DeepSeek 实际调用全部保留。独立复核核心 21/21、角色 16/16、非法输入边界 3/3。

最终 991 项功能汇总与私有远端安装、完整测试、40 项严格重放的实测证据在发布前补入正式说明。该草稿不证明这些尚待执行的发布步骤通过。

原样 Python 桥接保留 981 通过、10 项接口/输入差异；这与保持原意的 Go 验收分别报告。音视频角色主要使用原测试的合成观察，图片场景包含真实 PNG 观察。没有进行 H3 视频推理，不声称 MiniMax 内部实现或成片质量等价。
