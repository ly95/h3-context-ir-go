# 架构与合同

ContextIR 的持久化资产是 `Document`，不是一段经过润色的字符串。调用方可在任意步骤检查或编辑 IR，随后重新验证与编译。

## 分层

1. 根包：领域类型、稳定错误、严格 JSON、JSON Schema、纯合同验证、统一调用用量。
2. `compiler`：高层 Brief 编译与修订，类型化解释模式、职责、替换、内容权限、参考属性优先级；固定对白、镜头、摄影机、身份和输入准备要求由宿主管理。
3. `planner`：通过 Perceiver 收集或复用 Evidence；通过 Model 生成 Document；保护原始请求；检查观测出处；仅在明确配置时重新请求完整结构。
4. `h3`：唯一 Document 渲染路径、素材 manifest、标签分配、公开 H3 格式、运行时 Profile、内容哈希。`h3check` 负责写作规则；`budget`、`tokens`、`plan`、`lora` 提供可独立调用的确定性能力。
5. `deepseek` / `chatcompat`：显式配置的模型适配器与真实像素请求；`media`：显式本地解析、文件头、ffprobe/ffmpeg、抽帧、可选缓存和可注入 ASR。核心与内置包均仅依赖 Go 标准库。
6. `service` / `uploads`：可选 HTTP handler、编译记录与内容寻址上传；`comfy`：远端 ComfyUI HTTP 与图操作。库不自动监听或启动任务。
7. `cmd/contextir`：离线操作及显式模型编译 CLI；`cmd/contextir-upstream-eval`：原上游输入的真实模型验证；`cmd/contextir-eval`：保留早期自编 smoke 历史。

模型与感知适配器由宿主注入。核心验证与渲染不做 IO；`media` 只对显式 resolver 返回的本地文件执行配置好的媒体工具，`comfy` 只访问配置的端点。模型包不读取环境变量或自动下载素材。CLI 仅读取指定名称的凭据变量，不搜索 dotenv。CLW 的鉴权、资产读取、计费与 River 生命周期留在 CLW，ContextIR 没有对它的依赖。

## 来源与不可变输入

Asset ID 与顺序来自调用方。SourceRef 指明资产、轨道和可选的源时间区间。Evidence 来自调用方或感知器，并保存在最终 Document 中。Attribution 的 FactIDs 必须与事实来源对应。Claim 的 Origin 区分用户要求、观测和创意补充。

这些关系能校验“引用了哪个证据”，无法机械证明“这段自然语言完全由该证据推出”。这种语义质量需要评测，不能用关键词匹配假装验证。

模式与资产用途使用明确类型。未提供用途时由结构化模型合同解释；未得到合法结果就失败。模型不参与访问授权，不允许换模型或选择隐藏降级路径。

非空 Request.Bindings 是完整允许的来源/职责集合；有值的 Anchor 锁定目标时间，没有值则保留未指定语义。固定对白是不可修改输入，额外生成对白默认禁止。Coverage 描述实际观察的轨道和范围，默认要求完整；部分与未声明覆盖必须由调用方显式接纳。

## 规划与编译

Planner 的成功条件是完整 Document 通过根验证及原始请求保护。无效模型输出不会作为草稿返回；失败结果只保留已经收集的证据和模型调用用量。

高层编译先做确定性 intake，再观察实际素材、解释模式与职责、解析替换关系、内容权限和参考许可，构造宿主管理的结构约束，最后调用 Planner。写作模型只看到固定对白的槽位；宿主按原文回填、检查跨镜分片拼接、稳定人物描述及摄影机闭集。模型不能通过重复写回 Evidence 为自己制造事实。

引用骨架、保留关系和已确定画风不由写作模型重新抄写。输入观察按已声明职责投影给后续写作，权威 Evidence 原样保存。涉及环境、结构、分镜、植入/替换、音频或整张参考图作为帧的场景另做类型化最终叙事审核；发现需修复的内容回到同一个有界写作预算。审核的网络失败、取消和无效计量通过 `planner.StopValidation` 直接传播，不因重写正文而再付费。审核、写作与修复按实际顺序计量。

许可解析与正文写作使用不同的观察视图：前者读取原始源外观以判断明确改动，后者仅接收职责允许的身份或场景属性及规范化目标。主体引用不能捎带布景，环境引用不能捎带演员身份。多源属性在真实 asset ID 上记账；未观察到的用户指定属性保留为用户目标声明，不冒充观察。

音频属性也有类型化接收对象：voice 仅指向绑定说话人的声线，music style 指向新增配乐，beat 指向剪辑/动作节奏，SFX 指向新音效纹理。未使用的声线元数据不授权把声音属性转给引擎；独立环境声与用户授权的非语言发声仍合法。审核需引用实际来源、错误接收对象和输出片段，不能仅因听觉描述相似就判定误用。

固定对白的镜头、行 ID 与连续旗标同样约束表演叙事，原词仍由宿主回填。语义审核收到调用方投影授权、合并前源 ID 图和带来源类别的 claims，区分重演词语与复制音轨。可见文字除原文字节外还检查指定镜头；正文延续同一可读标牌不能绕过事件计数。修改时长等修订后也执行这些约束。生成英文的标点规范不会全局清洗用户原文。

`Compile` 默认在澄清未解决时返回 `needs_input`，不发布 prompt。显式 `ClarificationContinue` 才可沿已记录选择继续，问题与警告保留。内容与禁令冲突默认拒绝；显式 `ScopeConflictSuppliedWins` 支持上游的已提供文字优先策略并记录冲突与解决。`SilenceAll` 等结构化硬约束不被该策略覆盖。`Silent` 对应禁止新增配乐，仍可复制已提供 BGM；全面禁止音乐是另一项明确约束。

`Refine` 通过类型化修改重新运行同一编译流程，未修改的原输入、观察、固定文字和约束保留；目标尺寸改变必须重新计算派生准备指令。它不拼接旧 prompt，也不修改旧产物。

H3 Compile 不调用模型。所有章节、标签、镜头编号、对白标记与 manifest 均由同一个 Document 派生。字面正文和结构化 spans 分开，避免让模型自己编写未绑定的引用编号。

普通模式使用三段正文；首/尾帧模式增加对齐指令。全参考模式使用六段，显式解释引用的角色与保留关系。音频标签编号与底层输入 socket 编号分别维护。

## 时间

Time 使用整数毫秒；FPS 和实际播放时长使用有理数。Target.FrameCount 是可选的显式帧数选择。它出现时，Duration 必须是相同播放时长的最近毫秒表示；这只是表示精度转换，不会改变帧数。

`17k+5` 属于特定后端的执行约束。它不进入通用 Document schema，也不会使编译器自动舍入用户请求。CLI 的 Profile 选择是明确的。

## 错误与重试

错误包含稳定 Code、Stage、结构化 Issues 和可解包 Cause。公开 Error() 不拼接模型输出、素材 URI 或用户文本。调用方仍不应把任意 Cause 原样暴露给终端用户。

Planner 默认零次重试。有限重试只针对不合合同的完整模型结果，使用原始输入和安全字段诊断。传输失败、缺能力、取消、负用量报告均明确失败。调用方拥有任务级重试和幂等语义。

感知调用与规划调用分别计量；失败同样保留模型上报的用量。UsageInvalid 在已报告数量之外标记证据无效，例如超出输出 token 硬上限；此类记录不能作为收费依据。内容不合合同但真实有效的 token 用量不会伪装成零。

高层 `Result.Calls` 是单一账本。感知器实现 `MeteredPerceiver` 时所有实际尝试并入账本；决策对象内的调用仅为追踪副本，不重复求和。普通感知器以及不能汇报费用的 ASR 记为未计量，`UsageComplete=false` 并列出资产。显式本地、无模型调用的能力可报告空调用列表；无效计量证据与费用未知严格区分。

静态图片可报告完整视觉覆盖；抽样视频只报告实际帧的部分覆盖；ffprobe 只建立物理元数据，ASR 只建立其返回的词语。未听过的声音不能从文件名、notes 或无声帧中补造。部分覆盖必须由调用方明确接纳。`MediaPreparation` 记录后端需要的缩放/帧数指令，与源元数据分开；manifest 不表示这些 IO 已执行。

## 版本与扩展

Go API 与 IR 文档分别版本化。未知字段和版本拒绝，避免旧版静默丢失新信息。新目标模型需要自己的 compiler/capability profile；在有真实第二个后端之前，不引入万能视频 IR、插件注册中心或通用 DAG。

上游完整测试、原始断言、原始输入的真实模型解释与最终成片质量是不同证据。`conformance` 逐条记录原 nodeid、实际触及的 Go 函数、模型录制与未覆盖项。真实视频生成、人物一致性、音画同步和成片文字保真仍需实际 H3 推理评测，不能由 IR 测试代替。

当前实现边界与真实评测证据见 [READINESS.md](READINESS.md) 和 [evals](../evals/README.md)。v0.1.0 是早期基础版本，后续审计修复不通过重写旧标签发布。
