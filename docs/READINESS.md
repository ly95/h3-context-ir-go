# 实现范围与限制

H3 Context-IR Go 已实现独立的 Brief → Document → H3 流程，包括原生 Go 编译、修订、验证、引用绑定和上游公开的辅助能力。核心只依赖 Go 标准库；可选模型适配器依赖官方 OpenAI Go SDK，测试和开发入口使用 Go。

## 已实现能力

| 范围 | 实现 |
| --- | --- |
| IR 与持久化 | 版本化 Document/Evidence、严格 JSON 编解码、Schema、来源、稳定错误和调用用量 |
| 高层编译 | 五种模式、十六种职责、类型化模式/职责/许可/替换/属性投影、有限修复与结构化澄清 |
| 文字与镜头 | 固定及生成对白、跨镜连续分片、说话人、旁白、歌唱、原音轨 cue、可见文字、镜头与切点控制 |
| 引用与音频 | 身份与环境分离、首尾帧完整保留、音轨复制与属性引用、voice/music/beat/SFX 接收对象、参考属性优先级 |

| 验证与评估 | 公开 H3 文本规则、原始 controls、原生行为测试、固定语料、严格录制回放、离线评分与回归比较 |

## 调用方需要提供的能力

模型端点、模型名、凭据、输出上限和推理选项由宿主显式配置。模型调用可能失败或返回不合合同的结果；修复预算耗尽就返回错误，不自动切换模型。所有已发生的调用与有效用量都应随结果保留。

素材观察必须来自实际感知器或调用方明确提供的 Evidence/Card。文字 notes 不是观察。静态图可以有完整视觉覆盖；视频采样只观察实际采样帧，无法证明帧间运动或未听到的音频。ASR 只提供返回的词语，不证明音色、音乐、节奏或完整音频语义。默认 Planner 不接纳部分覆盖，调用方需显式授权。

`MediaPreparation` 是准备指令，实际裁剪、缩放、分段和转码由执行适配器完成。ComfyUI 客户端是远端 HTTP 集成，不随库分发推理运行时。服务包创建 handler，监听、鉴权、持久化、部署与应用计费由宿主负责。

## 格式与后端限制

`OfficialProfile` 描述公开 H3 格式。`ComfyUIProfile` 额外验证帧网格、画布、输入数量和已支持 socket；它不表示任意 ComfyUI 版本都具备同样能力。当前 profile 不实现独立的 `MiniMaxH3AddGuide` 工作流，Ref2VA 的 exact-frame anchors 会明确拒绝。

当前格式边界还包括可见文字中嵌套的 ASCII 双引号与独立的画外歌唱；不支持的表示会返回错误。用户文字不会被隐式清洗或截短。时长采用整数毫秒与有理数 FPS，帧对齐必须显式选择，不自动替换请求时长。

投影属性名是 opaque selector，实际来源由稳定的 subject/asset ID 决定。属性名若包含 `second picture` 等位置描述，输入重排后名称本身仍可能有散文歧义；新集成应使用 `wheels` 等不依赖输入位置的属性名。类型化绑定正确不代表所有自然语言都已无歧义。

## 质量证据的边界

Go 单元测试、固定上游语料和严格录制回放可以验证合同、来源、错误边界、算法和产物一致性。它们不能证明任意自然语言的理解正确，也不能替代当前模型服务的一次新调用。结构有效、语义审核通过和视频质量是不同证据。

本库不包含 MiniMax 私有 Context-IR 的内部实现、训练数据或模型。没有基于实际 H3 成片的人物一致性、音画同步、文字保真或质量等价保证。模型、服务与调用方素材的使用条款需要独立遵守，见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

## 发布树与历史版本

公开源码以当前 Go 源码、必要测试 fixture、来源清单和许可证为边界，不分发内部运行报告、源码快照或开发日志。将已有内部仓库转为公开仓库会同时公开其历史；发布新开源仓库应从审查后的干净源码建立初始历史，而不是直接切换旧仓库的可见性。

源码清理不会改写已经发布的标签或其 module ZIP。旧版本中的开发工具仍属于旧版本；清理后的发布必须使用新版本，并重新检查实际分发内容。
